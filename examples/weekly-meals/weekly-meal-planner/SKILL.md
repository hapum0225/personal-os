# 주간 식단 + 장보기 생성기

이번 주 컨디션·목표만 정하면 요일별 식단과 장보기 리스트를 만들어 준다.

> 유형: 삶

## 언제 이 스킬을 쓰는가
- 발동: "이번 주 식단", "장보기 리스트", "뭐 먹지", "meal plan"
- 발동하지 않음: 영양 진단, 의학적 식이 처방

## 작동 방식
### 1단계 · 이번 주 조건
- 목표(예: 가볍게 / 든든하게), 식이 제약(알레르기·비선호), 조리 가능 시간을 묻는다.

### 2단계 · 냉장고 확인
- 지금 있는 재료를 묻는다(있으면 그걸 먼저 소진하도록).

### 3단계 · 식단 + 장보기 생성
- 요일별 식단을 짜고, 겹치는 재료를 합쳐 **통합 장보기 리스트**를 만든다.

## 출력
`meal-plan-<YYYY-MM-DD>.md` 한 파일 — 요일별 식단 표 + 장보기 리스트(카테고리별).
