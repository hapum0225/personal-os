# 예제 · 자취 직장인 식단 (유형: 삶)

## 페르소나 (가상)
혼자 사는 직장인. 매주 "뭐 먹지"를 고민하고, 장을 봐도 빠뜨린 게 있어 두 번씩 마트에 간다.

## 인터뷰에서 나온 것
- **반복 소모**: 매주 식단 고민 + 장보기 누락으로 재방문(결정 + 정리 비용). 대조 기법으로 "메뉴만 정해지면 장보기는 쉬운데, 그 '정하기'에서 30분이 샌다"가 드러남.
- **OS Core**: **"이번 주 컨디션·목표만 정하면, 요일별 식단과 장보기 리스트가 자동으로 나오는 구조."** (구조형)
- **유형**: 삶 — 특정인에 종속되지 않아 누구나 그대로 쓸 수 있음.
- **첫 부품**: 주간 식단 + 장보기 생성기 (A 스킬)
- **형태**: A(스킬) — 조건을 물어 리스트를 생성하는 대화형이라 가장 가볍고 즉시 사용 가능.
