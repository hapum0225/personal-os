# 예제 (examples)

`personal-os` 인터뷰가 실제로 어떤 결과를 내는지 보여주는 예제 모음이다. 각 예제는 **가상의 페르소나**로 인터뷰를 끝까지 진행해 나온 산출물이다(실제 수강생 정보가 아님).

> 이 폴더는 학습·참고용이며, 플러그인 설치 payload에는 포함되지 않는다.

## 목록

| 예제 | 페르소나 | 형태 | 산출물 |
|---|---|---|---|
| [content-creator](./content-creator/) | 주 3회 영상을 올리는 1인 콘텐츠 크리에이터 | A (스킬) | `os-blueprint.md` + `weekly-content-review/` 스킬 폴더 |

각 예제 폴더의 `README.md`에 페르소나 배경과 인터뷰에서 무엇이 나왔는지 정리돼 있다.

> 평가(`evals/scenario-tests.md`)에서 쓰는 holdout 페르소나는 이 예제들과 **겹치지 않는** 별도 인물이다. 예제에 과적합한 산출물을 정답처럼 만들지 않기 위해서다.
