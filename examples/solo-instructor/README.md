# 예제 · 1인 강사 (유형: 개인)

## 페르소나 (가상)
온라인 강의를 혼자 운영하는 1인 강사. 수강생 20여 명 각자 진도와 질문이 달라, 매주 피드백을 한 명씩 처음부터 손으로 쓴다.

## 인터뷰에서 나온 것
- **반복 소모**: 수강생 20명에게 진도 맞춤 피드백을 매주 새로 작성(집중력 + 정리 비용). 스위치 스토리로 "한 명당 지난 기록을 다시 뒤져보는 10분"이 드러남.
- **OS Core**: **"수강생 이름과 이번 주 진도만 넣으면, 그 사람 맞춤 피드백 초안이 나오는 구조."** (구조형)
- **유형**: 개인 — 내 수강생 명단·커리큘럼·말투에 종속되어 다른 강사가 그대로 못 씀.
- **첫 부품**: 수강생 맞춤 피드백 초안기 (A 스킬)
- **형태**: A(스킬) — 정보를 물어 글을 정리·생성하는 대화형이라 가장 가볍고 즉시 사용 가능.
