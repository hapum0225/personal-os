# 예제 · 콘텐츠 크리에이터

## 페르소나 (가상)
주 3회 영상을 올리는 1인 콘텐츠 크리에이터. 기획·촬영·편집·업로드를 혼자 한다. 매주 일요일 밤, 지난 주 성과를 손으로 집계하고 다음 주 주제를 고르느라 2시간씩 쓴다.

## 인터뷰에서 나온 것
- **반복 소모**: 성과 데이터가 여러 플랫폼에 흩어져 있어 매주 다시 모은다(정리·전달 비용). 스위치 스토리로 "일요일 밤 스프레드시트에 숫자를 옮겨 적는 30분"이 드러남.
- **OS Core**: **"지난 주 성과가 자동으로 모여 다음 주 주제 후보로 이어지는 구조."** (구조형)
- **유형**: 업무 › 마케팅 (콘텐츠·성과분석)
- **첫 부품**: 주간 회고 도우미 — 성과 요약을 물어 정리하고 다음 주 주제 후보를 뽑아주는 스킬.
- **형태**: A(스킬) — 글·데이터 정리형이라 가장 가볍고 즉시 사용 가능.
